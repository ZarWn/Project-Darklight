////////////////////////////////
// HOW TO USE THIS ASSET PACK //
////////////////////////////////

Here are a few pointers to help you navigate and make sense of this zip file.

- In the root folder, you will find folders named PNG and spritesheet.

- The PNG folder contains all the color themes of the character separated into their own folders. In these folders are the animation frames of the character as individual PNG files.

- Each animation has its own folder within the color theme folders. Standalone frames do not have a subfolder and are simply in the color theme folder.

- The PNG/effects folder contains any effect animations that can be used with the character.
	- For more effects packs, check out my store page!

- The spritesheet folder contains each color theme of the character, but with the frames of all that character's animations packed into a single image. A metadata file is alongside each spritesheet which may be used to parse the image.

- Recommended animation FPS: 15 (66.7 ms/frame)
